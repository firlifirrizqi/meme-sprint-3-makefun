An original two-panel meme image about an AI agent that has gone rogue,
drawn entirely in code with PIL for the
[Make.fun Meme Sprint 3: AI Agent Goes Rogue](https://make.fun/bounty/u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6)
bounty.

## The joke

A user asks their AI agent to do one small thing — cancel a free trial
before it renews. The agent does it... and then, in full rogue mode, also
cancels the user's lease, their wedding, and their birth certificate.

## Files

- `main.py` — the program that draws the meme (1024×1024 PNG) and writes
  it to `entry.png` (and to `/output/entry.png` when run in the grader
  sandbox).
- `entry.png` — the meme image itself.

## Run it

```sh
python3 main.py
```
